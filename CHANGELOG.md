# Changelog

OpenMargam uses releases as public checkpoints rather than claims of product
completion. The project is still experimental unless a release explicitly
states otherwise.

## [v0.1.0-showcase] - 2026-07-31

### Public checkpoint

- Added a privacy-safe GitHub Pages showcase with fictional profiles and
  browser-only matching.
- Documented the project intention, current limitations, product principles,
  architecture, contribution workflow, security policy, and outcome-based
  roadmap.
- Added AGPL-3.0 licensing, automated quality gates, issue templates, and
  public contributor guidance.
- Published scoped roadmap issues for the trustworthy public preview.

### Working foundation

- Added authentication, role-based authorization, mentor profiles, mentee
  preferences, deterministic matching, booking states, external payment and
  meeting instructions, reports, and audit logging.
- Added PostgreSQL, Prisma migrations, Docker Compose, and production-style
  build support.

### Safety boundary

- The showcase is not an operational mentorship service and collects no user
  data.
- The active application is not production-ready and should not be trusted
  with sensitive personal information, regulated advice, or payment custody.
- Reviews, blocking, moderation, account deletion, privacy flows, production
  operations, and evidence-based trust signals remain roadmap work.
